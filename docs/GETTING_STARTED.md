# Getting Started & Execution Guide

This guide walks you through setting up the environment, installing dependencies, configuring paths, and running the complete automated pipeline for the **Country Data Fingerprint** project.

---

## Prerequisites

Ensure your system meets the following requirements:
* **Operating System**: Windows 10/11, macOS, or Linux (Ubuntu 20.04+ recommended).
* **Python**: `Python >= 3.10` (Python 3.10 or 3.11 recommended).
* **Environment Manager**: Miniforge3 / Anaconda / Miniconda, or standard `venv`.
* **Git**: Installed on your system.

---

## 1. Installation & Environment Setup

### Step 1: Clone the Repository
Open your terminal / Command Prompt and clone the repository:

```bash
git clone https://github.com/ilovecaffeine/country-data-fingerprint.git
cd country-data-fingerprint
```

### Step 2: Create & Activate Virtual Environment

#### Option A: Using Conda / Miniforge3 (Recommended)
```bash
# Create a new environment named 'fingerprint' with Python 3.10
conda create -n fingerprint python=3.10 -y

# Activate the environment
conda activate fingerprint
```

#### Option B: Using Python `venv`
```bash
# On Linux / macOS
python3 -m venv venv
source venv/bin/activate

# On Windows (Command Prompt / PowerShell)
python -m venv venv
venv\Scripts\activate
```

### Step 3: Install Required Dependencies
Install all required packages from `requirements.txt`:

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

## 3. Running the Master Pipeline

The entire project is orchestrated via `src/script/run_pipeline.py`. You can run the entire workflow end-to-end with a single command or execute individual stages.

### 3.1 Run Complete Pipeline (End-to-End)

To execute all processing stages, experiments, and visualizations sequentially:

```bash
python -m src.script.run_pipeline --step all --use_imputed True --drop_missing True
```

---

### 3.2 Command-Line Arguments (CLI Reference)

| Argument | Type | Choices / Default | Description |
| :--- | :--- | :--- | :--- |
| `--step` | `str` | `all`, `data`, `exp1`, `exp2`, `exp3`, `closed_loop` (Default: `all`) | Selects specific pipeline stage to execute. |
| `--use_imputed` | `bool` | `True`, `False` (Default: `True`) | Whether to use time-series imputed data (`True`) or raw unimputed data (`False`). |
| `--drop_missing` | `bool` | `True`, `False` (Default: `True`) | Whether to strictly drop countries with missing values (`True`) to guarantee 100% clean panel data. |

---

### 3.3 Running Individual Pipeline Stages

You can execute specific modular stages independently:

#### Stage 1: Data Processing & Panel Creation
Ingests raw CSVs, performs time-series imputation, validates data integrity, and splits panel datasets for Experiments 1, 2, and 3:

```bash
python -m src.script.run_pipeline --step data --use_imputed True --drop_missing True
```

#### Stage 2: Experiment 1 — Macro-Distance & Network Analysis
Calculates annual Euclidean and Cosine distance matrices ($2010$–$2024$), generates wide-format nearest neighbor summary CSVs, and exports interactive D3.js Hierarchical Edge Bundling (HEB) HTML charts:

```bash
python -m src.script.run_pipeline --step exp1
```

#### Stage 3: Experiment 2 — Country Classification
Benchmarking 9 classifiers on multi-class country identity, performing out-of-sample evaluation on the Test set ($2021$–$2024$), extracting feature importances, and generating misclassification error reports:

```bash
python -m src.script.run_pipeline --step exp2
```

#### Stage 4: Experiment 3 — Multi-Output Forecasting
Benchmarking 9 multi-output regressors on $1$-year ahead forecasting ($t+1$), performing Test set evaluation, generating per-feature $R^2$/MAE/RMSE metrics, global yearly drift boxplots, and Plotly interactive 4-quadrant stability maps:

```bash
python -m src.script.run_pipeline --step exp3
```

#### Stage 5: Closed-Loop Hybrid Pipeline
Passes forecasted future 20D fingerprints ($\hat{\mathbf{y}}_{2021-2024}$) from Experiment 3 into the Experiment 2 Extra Trees Classifier to test if identity is preserved in future predicted states:

```bash
python -m src.script.run_pipeline --step closed_loop
```

## 5. Troubleshooting & FAQ

### Issue 1: `ModuleNotFoundError: No module named 'src'` or `'config'`
**Solution**: Ensure you are running commands from the root directory using the `python -m` flag:
```bash
# Correct
python -m src.script.run_pipeline --step all

# Incorrect
python src/script/run_pipeline.py
```

### Issue 2: `[STOP PIPELINE]` (Empty Panel Data)
**Solution**: This happens if you run `--use_imputed False --drop_missing True` because raw unimputed World Bank data contains missing values for all 194 countries.
* To fix this, run with imputed data enabled:
  ```bash
  python -m src.script.run_pipeline --step all --use_imputed True --drop_missing True
  ```

### Issue 3: Interactive Plotly or D3.js HTML plots do not render in browser
**Solution**:
* D3.js HEB HTML files require an active internet connection to load the D3.js CDN (`https://d3js.org/d3.v7.min.js`).
* Open the `.html` files directly in any modern web browser (Google Chrome, Firefox, Microsoft Edge, or Safari).
